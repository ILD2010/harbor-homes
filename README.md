# Harbor Homes

Harbor Homes is a self-directed full-stack web development project built around a fictional home-services company specializing in HVAC, electrical, and plumbing services.

I created this project to practice building a realistic small-business web application from the ground up, combining a professional customer-facing website with backend functionality, authentication, database management, and customer service tools.

## Current Features

- Responsive multi-page business website
- Customer registration and login
- Secure password hashing and authentication
- Session-based customer accounts
- Customer dashboard
- Service request submission
- Customer service request history
- Individual service request details
- Authorization controls for customer data
- Account settings and profile management
- Password management
- Account deletion
- Responsive layouts for desktop, tablet, and mobile

## Technologies

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Jinja2

## Project Goals

Harbor Homes is designed to go beyond a traditional static portfolio website.

The goal of the project is to simulate the development of a real small-business web application and gain experience with:

- Full-stack application development
- Backend architecture
- Relational databases
- Authentication and authorization
- Application security
- Responsive UI development
- Business requirements
- Debugging and testing
- Production deployment

## Development Status

Harbor Homes is actively under development.

The customer-facing website and core customer portal functionality are implemented. Additional internal business functionality, including employee and administrative tools, is planned for future development.

## Security

Security is an important part of this project. The application is being developed with concepts such as password hashing, session-based authentication, authorization checks, database relationships, and protection against unauthorized access to customer resources.

Harbor Homes is also being used as a controlled environment for learning and practicing application security techniques.

## Disclaimer

Harbor Homes is a fictional company created for educational and portfolio purposes. It is not an operating home-services business.
